# SyncMate

> *Distance divides. Training unites.*

Сервис для совместных дистанционных тренировок с соревновательным режимом в реальном времени.

## Сборка и запуск сервера
Требования: Java 21

```bash
cd server
./gradlew bootRun
```


## Проверка работоспособности (API тесты)


```bash
cd server/tests
chmod +x test_api.sh && ./test_api.sh
```
